# Backlog

Ideas deliberately left out of the current build (see SPEC.md §9 for hard
out-of-scope items). Not scheduled.

- **Adaptive safe time**: measure a player's median answer time and quietly
  widen `safeAnswerTime` for very young players.
- **Parent/teacher report**: per-operation accuracy and speed over time, all local.
- **Number-bond hints**: after two misses on the same question, gently pulse the
  correct jelly (off by default).
- **Colour-blind palettes** and a high-contrast mode toggle.
- **Left-handed layout** option for touch (crab controls mirrored).
- **Fractions / decimals sections** reusing the same generator shape.
- **Daily seeded challenge**: same seed for everyone for one day (local only, no accounts).
- **Localised numerals** (e.g. Eastern Arabic digits) for the on-jelly numbers.
- **Reduced-motion mode** that disables screen shake and sway.
- **Haptics** on supported phones for splash hits.
- **Music tracks per section** (currently only short SFX and a soft ambient pad).

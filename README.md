# Tidelight Tally

An original math arcade game. Murkjellies drift down toward the Tidelight Reef,
each carrying a number. A sum appears at the top of the screen — the lantern-crab
answers by firing a pearl beam at the jelly showing the right result.

**Play it live:** https://piratekinginc.github.io/test-m6/

See [SPEC.md](SPEC.md) for the full design and difficulty specification.
